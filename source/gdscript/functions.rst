1.6. Функции
============

Функция — именованный блок кода, который выполняется при вызове. Функции
избавляют от повторения кода и разбивают программу на понятные части.


Объявление и вызов
------------------

.. example:: gdscript/functions/functions


Разбор:

- ``func greet() -> void:`` — функция без параметров, которая ничего не
  возвращает.
- ``func add(a: int, b: int) -> int:`` — функция с двумя параметрами типа ``int``.
  Параметры — переменные, значения которых передаются при вызове. После ``->``
  указан тип результата.
- ``return a + b`` — завершение функции и возврат результата.
- ``func is_alive(health: int) -> bool:`` — функция возвращает результат
  сравнения ``health > 0``, то есть ``true`` или ``false``. Такие функции дают
  проверке понятное имя: ``is_alive(health)`` читается проще, чем
  ``health > 0``.
- ``greet()`` и ``add(2, 3)`` — вызовы функций. При вызове ``add(2, 3)`` параметр
  ``a`` получает значение ``2``, ``b`` — ``3``.

Функции объявляются вне других функций, без отступа. Порядок объявления не важен:
``_ready`` может вызывать функции, объявленные ниже неё.


Значения по умолчанию
---------------------

Параметру можно задать значение по умолчанию. Такой параметр можно не передавать
при вызове.

.. example:: gdscript/functions/default_args


Параметры со значением по умолчанию записываются после обязательных.


Область видимости
-----------------

Переменная, объявленная внутри функции, — **локальная**: она существует только во
время выполнения этой функции. Переменная, объявленная вне функций, — **переменная
скрипта**: она доступна во всех функциях скрипта и сохраняет значение между
вызовами.

.. example:: gdscript/functions/scope


Переменная ``score`` объявлена вне функций и накапливает значение между вызовами
``add_points``. Переменная ``bonus`` создаётся заново при каждом вызове и
недоступна в ``_ready``.
