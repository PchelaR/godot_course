1.2. Переменные и типы
======================

Переменная — именованное хранилище значения. Значение переменной можно прочитать и
изменить во время работы программы.

.. in-game::

   Представьте, что Вы создаёте персонажа. У него есть имя, запас здоровья,
   скорость передвижения и признак того, жив ли он. Все эти данные меняются по ходу
   игры: персонаж получает урон, подбирает ускорение, погибает. Каждое такое
   значение хранится в своей переменной, а код игры читает и изменяет его: вычитает
   урон из здоровья, проверяет, не опустилось ли оно до нуля.


Объявление переменной
---------------------

Переменная объявляется ключевым словом ``var``:

.. code-block:: text

   var имя: Тип = значение

.. example:: gdscript/variables/variables


Разбор:

- ``var health: int = 100`` — объявление переменной ``health`` типа ``int`` со
  значением ``100``.
- ``print(health)`` — вывод текущего значения переменной.
- ``health = 75`` — присваивание нового значения. Ключевое слово ``var`` при этом не
  пишется: оно нужно только при объявлении.


Основные типы
-------------

.. list-table::
   :header-rows: 1
   :widths: 15 45 40

   * - Тип
     - Значения
     - Пример
   * - ``int``
     - Целые числа.
     - ``100``, ``-5``, ``0``
   * - ``float``
     - Дробные числа. Дробная часть отделяется точкой.
     - ``2.5``, ``-0.75``, ``10.0``
   * - ``String``
     - Текст в двойных кавычках.
     - ``"Рыцарь"``, ``""``
   * - ``bool``
     - Логическое значение: истина или ложь.
     - ``true``, ``false``

Тип отражает смысл данных: здоровье считается целыми единицами (``int``), скорость
может быть дробной (``float``), имя — это текст (``String``), а «жив ли персонаж» —
да или нет (``bool``).

Тип переменной задаётся при объявлении и не меняется. Если присвоить переменной
значение другого типа, например ``health = "много"``, редактор сообщит об ошибке
ещё до запуска игры.


Вывод типа
----------

Если значение задаётся сразу при объявлении, тип можно не писать явно: оператор
``:=`` присваивает переменной тип значения.

.. example:: gdscript/variables/inference


Переменная ``coins`` получила тип ``int``, ``damage`` — ``float``, ``title`` —
``String``. Запись ``var coins := 12`` равнозначна ``var coins: int = 12``.

В этой документации тип указывается всегда: явно или через ``:=``. Переменная,
объявленная без типа (``var coins = 12``), может хранить значения любых типов, и
ошибки с ними обнаруживаются только во время работы игры.


Вывод нескольких значений
-------------------------

Функция ``print`` принимает несколько значений через запятую и выводит их подряд
без разделителей. Функция ``prints`` выводит значения через пробел.

.. example:: gdscript/variables/print_values



Константы
---------

Константа — именованное значение, которое не меняется. Константа объявляется
ключевым словом ``const``.

Константы нужны для параметров игры, которые задаются один раз: максимальный запас
здоровья, скорость прыжка, размер инвентаря. Если число ``100`` записано в десяти
местах кода, при изменении баланса придётся найти и исправить все десять. Константа
хранит значение в одном месте, а её имя объясняет, что это за число.

.. example:: gdscript/variables/constants


Константа ``MAX_HEALTH`` объявлена вне функции, поэтому доступна во всём скрипте.
Попытка изменить константу, например ``MAX_HEALTH = 50``, приводит к ошибке.


Правила именования
------------------

- Имя состоит из букв, цифр и символа ``_`` и не начинается с цифры. Принято
  использовать только латинские буквы.
- Имена переменных записываются строчными буквами с подчёркиваниями:
  ``player_name``, ``max_speed``.
- Имена констант записываются прописными буквами: ``MAX_HEALTH``.
- Регистр учитывается: ``health`` и ``Health`` — разные имена.

.. mistakes::

   - **Ошибка «Cannot assign a value of type…».** В переменную с типом кладут значение другого типа: например, строку в ``int``.
   - **``var x := null`` не работает.** По ``null`` нельзя вывести тип. Укажите тип явно: ``var x: Node = null``.
   - **Константу нельзя изменить.** ``const`` задаётся один раз. Для изменяемого значения нужен ``var``.
