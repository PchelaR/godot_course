1.11. Классы
============

Класс — описание объектов одного вида: какие данные они хранят и какие действия
выполняют. Объект, созданный по классу, называется **экземпляром** класса.

Каждый скрипт GDScript является классом. Строка ``extends Node`` в предыдущих
примерах означала, что скрипт — класс, созданный на основе встроенного класса
``Node``.


Объявление класса
-----------------

Класс ``Weapon`` описывает оружие с названием и уроном. Он хранится в отдельном
файле ``weapon.gd``, не прикреплённом ни к одному узлу. Такой файл создаётся в
панели **FileSystem**: правый клик по папке → **Create New → Script**. В окне
создания скрипта в поле **Inherits** укажите ``RefCounted``.

.. example:: gdscript/classes/weapon


Разбор:

- ``class_name Weapon`` — глобальное имя класса. По этому имени класс доступен во
  всех скриптах проекта.
- ``extends RefCounted`` — класс создан на основе встроенного класса
  ``RefCounted``. Это базовый класс для объектов, которые не являются узлами и не
  размещаются в сцене. Оружию в инвентаре не нужно ни изображение на экране, ни
  место в дереве узлов — это просто данные. Объекты ``RefCounted`` удаляются из
  памяти автоматически, когда перестают использоваться.
- ``var title: String`` и ``var damage: int`` — **поля**: переменные, которые
  есть у каждого экземпляра класса. Каждый экземпляр хранит собственные значения.
- ``func _init(...)`` — **конструктор**: функция, которая вызывается при
  создании экземпляра и задаёт начальные значения полей.
- ``func describe() -> String`` — **метод**: функция класса, которая работает с
  полями своего экземпляра.


Наследование
------------

Класс можно создать на основе другого класса. Новый класс — **наследник** —
получает все поля и методы исходного класса и может добавлять свои.

.. example:: gdscript/classes/magic_staff


Разбор:

- ``extends Weapon`` — ``MagicStaff`` наследует класс ``Weapon``: у него есть поля
  ``title``, ``damage`` и метод ``describe``.
- ``var mana_cost: int`` — новое поле, которого нет у ``Weapon``.
- ``super(weapon_title, weapon_damage)`` — вызов конструктора исходного класса,
  чтобы он заполнил поля ``title`` и ``damage``.
- ``func describe()`` — метод с тем же именем, что у ``Weapon``, заменяет его для
  экземпляров ``MagicStaff``. ``super.describe()`` вызывает исходную версию метода,
  к результату которой добавляется стоимость маны.


Создание экземпляров
--------------------

.. example:: gdscript/classes/classes


Разбор:

- ``Weapon.new("Меч", 10)`` — создание экземпляра. Аргументы ``new`` передаются в
  конструктор ``_init``.
- ``sword.describe()`` и ``sword.damage`` — обращение к методам и полям
  экземпляра через точку.
- ``staff is Weapon`` — проверка, является ли объект экземпляром класса. Результат
  ``true``, так как ``MagicStaff`` — наследник ``Weapon``.
- ``var spare: Weapon = null`` — ``null`` означает отсутствие объекта. Переменная
  типа класса может хранить ``null``, пока объект не создан. Обращение к полю или
  методу через ``null`` приводит к ошибке во время работы игры.


Классы узлов
------------

Встроенные узлы Godot тоже связаны наследованием: все типы узлов — наследники
класса ``Node``. Поэтому скрипт с ``extends Node`` можно прикрепить к узлу любого
типа, а скрипт с ``extends`` конкретного типа — только к узлу этого типа или его
наследника.

.. mistakes::

   - **Ошибка «Class "…" hides a global script class».** Два скрипта с одинаковым ``class_name``.
   - **Тип из ``class_name`` не виден в другом скрипте.** Скрипт с ошибкой не сохранён или не скомпилировался. Исправьте ошибки в нём.
