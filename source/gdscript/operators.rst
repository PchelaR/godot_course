1.3. Операторы
==============

Оператор — символ или слово, выполняющее действие над значениями: сложение,
сравнение, логическую проверку.


Арифметические операторы
------------------------

.. example:: gdscript/operators/arithmetic


.. list-table::
   :header-rows: 1
   :widths: 15 85

   * - Оператор
     - Действие
   * - ``+``, ``-``, ``*``
     - Сложение, вычитание, умножение.
   * - ``/``
     - Деление. Если оба числа целые (``int``), результат тоже целый: дробная часть
       отбрасывается, поэтому ``7 / 2`` равно ``3``. Если хотя бы одно число
       дробное (``float``), результат дробный: ``7.0 / 2.0`` равно ``3.5``.
       Строку с делением двух целых чисел редактор отмечает предупреждением о
       целочисленном делении. Это не ошибка, а напоминание о том, что дробная
       часть будет потеряна.
   * - ``%``
     - Остаток от деления: ``7 % 2`` равно ``1``.
   * - ``**``
     - Возведение в степень: ``7 ** 2`` равно ``49``.


Операторы присваивания
----------------------

Запись ``coins += 5`` — сокращение для ``coins = coins + 5``. Аналогично работают
``-=``, ``*=``, ``/=``.

.. example:: gdscript/operators/assignment



Операторы сравнения
-------------------

Сравнение возвращает значение типа ``bool``: ``true`` или ``false``.

.. example:: gdscript/operators/comparison


.. list-table::
   :header-rows: 1
   :widths: 15 85

   * - Оператор
     - Условие
   * - ``==``
     - Равно. Не путайте с ``=`` — оператором присваивания.
   * - ``!=``
     - Не равно.
   * - ``>``, ``<``
     - Больше, меньше.
   * - ``>=``, ``<=``
     - Больше или равно, меньше или равно.


Логические операторы
--------------------

Логические операторы объединяют значения типа ``bool``.

.. example:: gdscript/operators/logical


- ``a and b`` — ``true``, если оба значения ``true``.
- ``a or b`` — ``true``, если хотя бы одно значение ``true``.
- ``not a`` — меняет значение на противоположное.


Преобразование типов
--------------------

Операторы работают со значениями совместимых типов. Сложить строку и число
напрямую нельзя: ``"Очки: " + 42`` вызовет ошибку. Для преобразования
используются встроенные функции:

- ``int(значение)`` — в целое число; дробная часть отбрасывается;
- ``float(значение)`` — в дробное число;
- ``str(значение)`` — в строку.

.. example:: gdscript/operators/conversion


Оператор ``+`` для строк выполняет склеивание: ``"Очки: " + "42"`` даёт
``"Очки: 42"``.

.. mistakes::

   - **``7 / 2`` даёт ``3``.** Деление двух целых чисел целое. Нужна дробь — сделайте одно из чисел дробным: ``7 / 2.0``.
   - **Условие всегда истинно.** В условии ``=`` вместо ``==``. ``=`` присваивает, ``==`` сравнивает.
   - **Сравнение дробей не срабатывает.** ``0.1 + 0.2 == 0.3`` ложно из-за погрешности. Используйте :godot:`@GlobalScope.is_equal_approx()`.
