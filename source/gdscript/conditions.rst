1.4. Условия
============

Условие выполняет блок кода только в том случае, если выражение истинно.


if, elif, else
--------------

.. example:: gdscript/conditions/if_else


Разбор:

- ``if health <= 0:`` — если выражение истинно, выполняется блок с отступом под
  этой строкой.
- ``elif health < 30:`` — проверяется, только если предыдущие условия ложны.
  Блоков ``elif`` может быть сколько угодно.
- ``else:`` — выполняется, если все условия выше ложны.

Проверки идут сверху вниз, и выполняется только первый подходящий блок. Блоки
``elif`` и ``else`` необязательны.


Условное выражение
------------------

Когда нужно выбрать одно из двух значений, используется условное выражение:
``значение_1 if условие else значение_2``.

.. example:: gdscript/conditions/ternary



match
-----

Конструкция ``match`` сравнивает значение с набором вариантов и выполняет блок
первого совпавшего.

.. example:: gdscript/conditions/match


Разбор:

- ``match command:`` — значение, которое сравнивается с вариантами.
- ``"attack", "shoot":`` — несколько вариантов через запятую: блок выполнится при
  совпадении с любым из них.
- ``_:`` — вариант по умолчанию: выполняется, если не совпал ни один из
  предыдущих.

``match`` удобнее цепочки ``if``–``elif``, когда одно значение сравнивается с
несколькими конкретными вариантами.
