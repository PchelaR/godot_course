1.1. Первый скрипт
==================

Скрипт — файл с кодом на GDScript, прикреплённый к :term:`узлу <Узел>`. Скрипт
определяет поведение узла: что он делает при запуске игры и во время её работы.

Все примеры этого раздела запускаются одинаково: скрипт прикрепляется к узлу в
пустой сцене, сцена запускается, результат выводится в панель **Output** редактора.


Создание сцены
--------------

1. В панели **Scene** в левой части редактора нажмите **Other Node**.
2. В открывшемся окне найдите и выберите узел **Node**, нажмите **Create**.
   В панели **Scene** появится узел с именем ``Node``.
3. Сохраните сцену: **Scene → Save Scene** (:kbd:`Ctrl+S`, в macOS
   :kbd:`Cmd+S`). Укажите имя файла ``main.tscn``.


Прикрепление скрипта
--------------------

1. Нажмите правой кнопкой мыши на узел ``Node`` в панели **Scene** и выберите
   **Attach Script**.
2. Проверьте параметры в окне **Attach Node Script** и нажмите **Create**.

.. screenshot:: 1

   Окно **Attach Node Script** для узла ``Node``.

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Параметр
     - Значение
   * - **Language**
     - Язык скрипта: **GDScript**.
   * - **Inherits**
     - Тип узла, который расширяет скрипт: **Node**.
   * - **Template**
     - Шаблон начального кода. Если флажок снят, файл будет содержать только
       строку ``extends Node``.
   * - **Built-in Script**
     - Хранение скрипта внутри файла сцены. Флажок должен быть снят: скрипт
       сохраняется отдельным файлом.
   * - **Path**
     - Путь к файлу скрипта. Godot предлагает сохранить его рядом со сценой под
       тем же именем: ``main.gd``. Префикс ``res://`` обозначает папку проекта.

После нажатия **Create** откроется редактор кода с содержимым скрипта.

Замените всё содержимое скрипта следующим кодом:

.. example:: gdscript/first_script/first_script


Запустите сцену клавишей :kbd:`F6` (в macOS — :kbd:`Cmd+R`). Откроется пустое окно
игры, а в панели **Output** в нижней части редактора появится текст, показанный под
кодом в блоке «Вывод». Закройте окно игры, чтобы вернуться в редактор.


Разбор
------

``extends Node``
   Скрипт расширяет узел типа ``Node``: добавляет к нему поведение. После
   ``extends`` указывается тип узла, к которому прикрепляется скрипт.

``func _ready() -> void:``
   Объявление функции ``_ready``. Функция — именованный блок кода. Функцию
   ``_ready`` движок вызывает сам, когда узел добавлен в сцену и готов к работе.
   Запись ``-> void`` означает, что функция не возвращает результат.

``print("Привет, Godot!")``
   Вызов встроенной функции ``print``, которая выводит значение в панель
   **Output**. Текст записывается в двойных кавычках.


Отступы
-------

Код, принадлежащий функции, записывается с отступом относительно строки ``func``.
GDScript определяет границы блоков кода по отступам, поэтому они обязательны. Для
отступа используется клавиша :kbd:`Tab`.

Если удалить отступ перед ``print``, редактор подчеркнёт строку красным и выведет
сообщение об ошибке в нижней части редактора кода. Скрипт с ошибкой не выполняется:
при запуске сцены Godot выведет сообщение об ошибке.


Файлы примеров
--------------

Все примеры раздела собраны в проекте :project:`examples`. Распакуйте архив и
откройте проект в менеджере проектов кнопкой **Import**. Примеры находятся в
папке ``gdscript``; чтобы запустить пример, прикрепите его скрипт к узлу ``Node``
вместо ``main.gd``.
