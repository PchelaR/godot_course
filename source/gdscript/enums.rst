1.10. Перечисления
==================

Перечисление (``enum``) — набор именованных констант. Перечисления описывают
значения, которые может принимать параметр: состояние персонажа, уровень
сложности, тип предмета.


Объявление и использование
--------------------------

.. example:: gdscript/enums/enums


Разбор:

- ``enum State { IDLE, RUN, JUMP }`` — перечисление ``State`` с тремя
  значениями. Каждому имени автоматически присваивается целое число по порядку,
  начиная с нуля: ``IDLE`` — ``0``, ``RUN`` — ``1``, ``JUMP`` — ``2``.
- ``var state: State = State.IDLE`` — переменная типа ``State``. Значения
  перечисления записываются через точку после его имени.
- ``print(state)`` — выводит число, соответствующее значению.
- ``State.keys()[state]`` — ``keys()`` возвращает массив имён значений; по индексу
  из него получается имя текущего значения.
- ``match state:`` — перечисления удобно разбирать конструкцией ``match``.

Перечисление делает код понятнее, чем числа: запись ``state = State.JUMP``
однозначна, а ``state = 2`` требует помнить, что означает ``2``.
