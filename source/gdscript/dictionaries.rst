1.8. Словари
============

Словарь (``Dictionary``) хранит пары «ключ — значение». В отличие от массива,
значения в словаре находятся не по номеру, а по ключу: имени характеристики,
названию предмета, идентификатору уровня.

.. in-game::

   Представьте характеристики персонажа: здоровье, мана, сила, ловкость. Или цены в
   магазине: меч — 50 монет, щит — 30. Такие значения удобно искать не по номеру, а
   по названию: «сколько стоит щит?», «какая у персонажа сила?». Словарь хранит пары
   «название — значение» и находит значение по названию.


Создание и доступ к значениям
-----------------------------

.. example:: gdscript/dictionaries/dictionaries


Разбор:

- ``{ "name": "Рыцарь", "health": 100 }`` — словарь записывается в фигурных
  скобках. Ключ отделяется от значения двоеточием, пары — запятыми.
- ``player["name"]`` — чтение значения по ключу.
- ``player["health"] = 80`` — изменение значения существующего ключа.
- ``player["level"] = 2`` — добавление новой пары: ключа ``level`` в словаре не
  было.
- ``has(ключ)`` — проверка наличия ключа.
- ``get(ключ, значение_по_умолчанию)`` — чтение значения; если ключа нет,
  возвращается значение по умолчанию. Например, если у персонажа ещё нет маны,
  её запас считается равным нулю.
- ``erase(ключ)`` — удаление пары.
- ``size()`` — количество пар.

Чтение отсутствующего ключа через квадратные скобки, например ``player["mana"]``,
приводит к ошибке во время работы игры. Если ключа может не быть, используйте
``get``.


Типизированный словарь и перебор
--------------------------------

Когда все ключи и все значения одного типа — как в прайс-листе магазина, где
название предмета соответствует цене, — типы указываются в квадратных скобках:
``Dictionary[String, int]``. Цикл ``for`` перебирает ключи словаря в порядке
добавления.

.. example:: gdscript/dictionaries/dictionary_loop


- ``keys()`` — массив всех ключей;
- ``values()`` — массив всех значений.
