1.9. Строки
===========

Строка (``String``) — последовательность символов. Строки используются для имён,
текста интерфейса, сообщений.


Методы строк
------------

.. example:: gdscript/strings/strings


- ``length()`` — количество символов;
- ``to_upper()`` и ``to_lower()`` — преобразование в верхний и нижний регистр;
- ``title[0]`` — символ по индексу; нумерация, как и в массивах, начинается с
  нуля;
- ``begins_with(текст)`` и ``ends_with(текст)`` — проверка начала и конца строки;
- ``текст in строка`` — проверка, содержит ли строка указанный текст;
- ``replace(что, на_что)`` — замена всех вхождений;
- ``split(разделитель)`` — разбиение строки на массив частей.

Методы строк не изменяют исходную строку, а возвращают новую: после всех вызовов
переменная ``title`` по-прежнему содержит ``Godot Engine``.


Форматирование
--------------

Чтобы вставить значения в текст, используется оператор ``%`` или метод
``format``.

.. example:: gdscript/strings/formatting


Разбор:

- ``"%s: %d HP" % [player_name, health]`` — в строке-шаблоне заполнители
  заменяются значениями из массива по порядку. ``%s`` — любое значение в виде
  текста, ``%d`` — целое число.
- ``"Скорость: %.1f" % speed`` — ``%.1f`` выводит дробное число с одним знаком
  после точки, с округлением. Если значение одно, массив не нужен.
- ``"{name}: {hp} HP".format({...})`` — заполнители в фигурных скобках
  заменяются значениями из словаря по ключам.


Специальные символы
-------------------

Некоторые символы записываются в строке через обратную косую черту:

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Запись
     - Символ
   * - ``\n``
     - Перенос строки. Пример выше выводит текст в две строки.
   * - ``\"``
     - Двойная кавычка внутри строки.
   * - ``\\``
     - Обратная косая черта.
