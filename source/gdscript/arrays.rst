1.7. Массивы
============

Массив (``Array``) — упорядоченный список значений.

.. in-game::

   Представьте инвентарь персонажа: меч, щит, зелье. Предметов может быть сколько
   угодно: они добавляются при подборе и исчезают при использовании. Завести
   отдельную переменную под каждый предмет не получится — заранее неизвестно,
   сколько их будет. Массив хранит весь список в одной переменной, а его размер
   меняется по ходу игры. Так же хранятся враги на уровне, точки маршрута патруля,
   рекорды игроков.


Создание и доступ к элементам
-----------------------------

.. example:: gdscript/arrays/arrays


Разбор:

- ``var items: Array[String] = ["меч", "щит"]`` — массив строк. Тип элементов
  указывается в квадратных скобках после ``Array``. Значения перечисляются через
  запятую в квадратных скобках.
- ``items[0]`` — обращение к элементу по индексу, то есть по номеру позиции.
  Нумерация начинается с нуля: первый элемент имеет индекс ``0``, второй — ``1``.
- ``items[-1]`` — отрицательный индекс отсчитывается с конца: ``-1`` — последний
  элемент.
- ``items[1] = "лук"`` — замена элемента.

Обращение к несуществующему индексу, например ``items[10]`` для массива из двух
элементов, приводит к ошибке во время работы игры.


Методы
------

Метод — функция, которая принадлежит значению и вызывается через точку:
``items.append("зелье")``. В примере выше использованы методы:

- ``size()`` — количество элементов: сколько предметов в инвентаре;
- ``append(значение)`` — добавление в конец: персонаж подобрал предмет;
- ``erase(значение)`` — удаление первого элемента с указанным значением: предмет
  использован или выброшен;
- ``has(значение)`` — проверка наличия значения, возвращает ``bool``: есть ли у
  персонажа ключ от двери.

Другие часто используемые методы:

.. example:: gdscript/arrays/array_methods


- ``sort()`` — сортировка по возрастанию;
- ``pop_back()`` — удаление последнего элемента с возвратом его значения;
- ``insert(индекс, значение)`` — вставка значения на указанную позицию;
- ``clear()`` — удаление всех элементов;
- ``is_empty()`` — проверка, пуст ли массив.


Перебор элементов
-----------------

Цикл ``for`` перебирает элементы массива по порядку. Перебор нужен, когда одно и то
же действие выполняется для каждого элемента: подсчитать общую стоимость предметов,
нанести урон всем врагам в радиусе взрыва, проверить, собраны ли все ключи уровня.

.. example:: gdscript/arrays/array_loop


Первый цикл получает сами значения элементов. Второй перебирает индексы от ``0``
до ``scores.size() - 1`` и обращается к элементам по индексу — этот вариант нужен,
когда важна позиция элемента.
