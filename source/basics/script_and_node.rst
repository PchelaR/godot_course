2.1. Скрипт и узел
==================

Конструкции из раздела «GDScript» в Godot применяются не сами по себе, а для
управления узлами. Скрипт, прикреплённый к узлу, читает и меняет его данные,
вызывает его функции и отвечает на события движка.


Где применяется изученное
-------------------------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - Конструкция
     - Применение в Godot
   * - Классы и наследование
     - Каждый тип узла — встроенный класс. Скрипт с ``extends`` — наследник этого
       класса и получает все его возможности.
   * - Переменные
     - Данные узла — положение, размер, поворот — хранятся в переменных его
       класса. Собственные переменные скрипта хранят состояние объекта: здоровье,
       скорость, счёт.
   * - Функции
     - Движок сам вызывает функции скрипта в нужные моменты: при появлении узла, на
       каждом кадре. Узлы также предоставляют готовые функции — методы.
   * - Условия
     - Реакция на ситуацию: здоровье закончилось, нажата клавиша, враг рядом.
   * - Циклы
     - Обработка групп объектов: всех врагов на уровне, всех предметов в инвентаре.
   * - Массивы и словари
     - Наборы данных: инвентарь, характеристики персонажа, список уровней.
   * - Перечисления
     - Состояния объекта: персонаж стоит, бежит или прыгает.


Скрипт — наследник узла
-----------------------

В статье о классах наследник получал поля и методы исходного класса. Скрипт с
``extends Node2D`` — наследник встроенного класса :godot:`Node2D`, поэтому в коде
скрипта доступны все переменные и функции этого класса. Их не нужно объявлять:
они уже есть у узла.

Переменные встроенного класса называются **свойствами** узла. Они же отображаются
в панели **Inspector**, когда узел выбран в редакторе.


Свойства узла
-------------

:godot:`Node2D` — базовый тип для объектов двумерной игры. У каждого такого узла
есть положение на экране, поворот и масштаб.

.. example:: basics/script_and_node/properties

Разбор:

- :godot:`Node2D.position` — положение узла. Значение имеет тип
  :godot:`Vector2`: пара чисел ``x`` и ``y``.
- ``Vector2(100, 50)`` — создание значения типа ``Vector2``: ``x`` равно ``100``,
  ``y`` равно ``50``.
- ``position.x`` — обращение к отдельной составляющей вектора.
- :godot:`Node2D.scale` — масштаб узла, тоже ``Vector2``. ``Vector2(2, 2)``
  увеличивает узел в два раза по ширине и высоте. Значение ``Vector2(1, 1)`` —
  исходный размер.

Координаты измеряются в пикселях. Точка ``(0, 0)`` — левый верхний угол окна игры,
ось ``x`` направлена вправо, ось ``y`` — **вниз**. Положение ``(100, 50)``
означает: 100 пикселей вправо и 50 пикселей вниз от левого верхнего угла.

.. fun-fact::

   Ось ``y``, направленная вниз, досталась играм от кинескопных мониторов. Луч
   рисовал изображение строка за строкой — слева направо и сверху вниз, — и в
   видеопамяти кадр хранился в том же порядке, начиная с левого верхнего угла.
   Номер строки растёт вниз, а вместе с ним и координата ``y``.

Составляющие ``Vector2`` хранятся как ``float``, поэтому в выводе числа указаны с
дробной частью.


Методы узла
-----------

Функции встроенного класса называются **методами** узла. Скрипт вызывает их так же,
как собственные функции.

.. example:: basics/script_and_node/methods

Разбор:

- :godot:`Node.get_child_count()` — возвращает количество дочерних узлов, то есть
  узлов, вложенных в текущий. Тип результата — ``int``.
- ``Node.new()`` — создание нового узла типа :godot:`Node`. Узел создан, но пока не
  входит в сцену.
- :godot:`Node.add_child()` — добавляет переданный узел в сцену как дочерний для
  текущего.
- :godot:`Node.get_parent()` — возвращает родительский узел, то есть узел, в
  который вложен текущий.
- ``self`` — ссылка на объект, которому принадлежит скрипт. Сравнение
  ``child.get_parent() == self`` проверяет, что родителем нового узла стал узел
  со скриптом.


Функции, которые вызывает движок
--------------------------------

Скрипт не запускается сверху вниз, как программа. Движок вызывает его функции в
определённые моменты:

- ``_ready()`` — один раз, когда узел появился в сцене и готов к работе;
- ``_process(delta)`` — на каждом кадре, пока узел находится в сцене. Игра
  выводит изображение много раз в секунду, обычно 60 и более; перед выводом
  каждого кадра движок вызывает ``_process`` у всех узлов.

Пример ниже вращает изображение на экране.

.. example:: basics/script_and_node/spinner

Чтобы запустить пример:

1. Создайте сцену с корневым узлом :godot:`Sprite2D` (**Other Node** → **Sprite2D**).
   Этот узел отображает изображение.
2. Перетащите файл ``icon.svg`` из панели **FileSystem** в поле **Texture** панели
   **Inspector**. Файл ``icon.svg`` есть в каждом новом проекте Godot.
3. Сохраните сцену, прикрепите к узлу скрипт с кодом примера и запустите сцену
   клавишей :kbd:`F6` (в macOS — :kbd:`Cmd+R`).

Иконка Godot появится в окне игры и будет непрерывно вращаться. Тот же пример
можно запустить прямо на этой странице:

.. godot-demo:: basics/script_and_node/spinner
   :title: Вращение иконки

Разбор:

- ``extends Sprite2D`` — скрипт расширяет узел :godot:`Sprite2D`, наследника
  ``Node2D``. Поэтому у него есть свойства ``position`` и ``rotation``.
- ``position = get_viewport_rect().size / 2`` — в ``_ready`` узел перемещается в
  центр окна. Метод :godot:`CanvasItem.get_viewport_rect()` возвращает
  прямоугольник видимой области игры; его свойство ``size`` — ширина и высота окна
  в виде ``Vector2``. Деление вектора на ``2`` делит обе составляющие и даёт
  координаты центра.
- ``func _process(delta: float)`` — ``delta`` — время в секундах, прошедшее с
  предыдущего кадра. При 60 кадрах в секунду это примерно ``0.0167``.
- :godot:`Node2D.rotation` — угол поворота узла в **радианах**. Полный оборот —
  примерно ``6.28`` радиана (2π), ``1`` радиан — около 57 градусов. Увеличение
  угла поворачивает узел по часовой стрелке, уменьшение — против.
- ``rotation += turn_speed * delta`` — на каждом кадре угол увеличивается на
  ``turn_speed * delta``. За секунду сумма всех ``delta`` равна ``1``, поэтому
  узел поворачивается на ``turn_speed`` радиан в секунду, то есть на 2 радиана.

Умножение на ``delta`` делает скорость независимой от частоты кадров. Без него
узел поворачивался бы на 2 радиана за кадр: на компьютере с 60 кадрами в секунду
это 120 радиан в секунду, а с 144 кадрами — 288. С ``delta`` скорость одинакова
на любом компьютере.

.. mistakes::

   - **Ошибка «Invalid call. Nonexistent function».** Метод вызывают у узла другого типа: скрипт расширяет не тот класс. Проверьте ``extends``.
   - **Скрипт не работает.** Скрипт создан, но не прикреплён к узлу.
