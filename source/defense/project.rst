4.2. Проект
===========

Создайте новый проект Godot с рендерером **Compatibility**: игра пойдёт и на
компьютере, и в браузере.

Картинок в игре нет вообще: карта, башни и враги — простые фигуры из узлов
:godot:`Polygon2D` и :godot:`Line2D`. Фигуры рисуются по своим точкам, а не
пикселями картинки, и при любом увеличении остаются чёткими. Поэтому настройки
экрана будут простыми.


Экран
-----

В **Project → Project Settings** откройте раздел **Display → Window**:

- **Viewport Width** — ``1152``, **Viewport Height** — ``648``. Это размер по
  умолчанию для новых проектов Godot, пропорции 16:9, как у большинства
  мониторов и телефонов, положенных набок.
- **Stretch → Mode** — **canvas_items**. Игра рисуется сразу в размере окна:
  фигуры и текст остаются чёткими при любом окне.
- **Stretch → Aspect** — **keep**. Пропорции экрана сохраняются: на окне другой
  формы по краям появятся полосы, но карта не растянется и не обрежется.

Цвет фона задайте в **Rendering → Environment → Default Clear Color** — светлый
``#fdf4e3``. На нём будет лежать карта.


Шрифт и тема
------------

Надписи в игре будут ретро-шрифтом **Press Start 2P**. Он бесплатный, его можно
использовать в своих играх по лицензии OFL, и в нём есть русские буквы. Шрифт
лежит в готовом проекте главы, а ещё его можно скачать с `Google Fonts
<https://fonts.google.com/specimen/Press+Start+2P>`_.

1. Создайте папку ``assets``, в ней ``ui``, и положите туда ``press_start_2p.ttf``
   вместе с лицензией ``OFL.txt``.
2. Шрифт, размер и цвет надписей нужны всем экранам игры, поэтому зададим их в
   :term:`теме <Тема>`, как в статье «Интерфейс». Создайте папку ``theme`` и в
   ней через **Create New → Resource...** ресурс :godot:`Theme` ``theme.tres``.
3. В инспекторе темы **Default Font** — наш шрифт, **Default Font Size** — ``16``.
4. Внизу редактора откройте панель **Theme**, добавьте тип :godot:`Label` и в его
   цветах задайте **Font Color** — тёмный ``#2b211c``: фон светлый.

Сглаживание шрифта в настройках импорта (**Antialiasing**) оставьте включённым:
экран растягивается под любое окно, и без сглаживания буквы на некоторых размерах
станут неровными.


Части игры
----------

Файлы разложим по частям игры, а не по типам: у карты своя папка ``map``, у врага
— ``enemy``, и в каждой лежат её сцена, скрипт и ресурсы. Когда понадобится
поправить врага, всё про него будет в одном месте. Файлы и папки называем в
``snake_case``, узлы и классы — с большой буквы. Папки будем создавать по мере
надобности.

.. mistakes::

   - **Фигуры растягиваются по ширине окна.** **Stretch → Aspect** не **keep**.
