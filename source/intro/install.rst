0.4. Установка Godot
====================

Скачивание
----------

Godot скачивается с официального сайта: `godotengine.org/download
<https://godotengine.org/download>`_. Сайт определяет операционную систему
автоматически и предлагает две сборки последней версии:

- **Godot Engine** — стандартная сборка с поддержкой GDScript;
- **Godot Engine – .NET** — сборка с поддержкой C#.

Для работы с этой документацией нужна стандартная сборка — верхняя кнопка на
странице загрузки.


Установка
---------

Godot не требует установки: архив достаточно распаковать.

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Система
     - Действия
   * - Windows
     - Распакуйте архив в любую папку и запустите файл ``Godot_v4.7…_win64.exe``.
   * - macOS
     - Распакуйте архив и переместите ``Godot.app`` в папку «Программы»
       (Applications).
   * - Linux
     - Распакуйте архив и запустите исполняемый файл ``Godot_v4.7…_linux.x86_64``.


Менеджер проектов
-----------------

При запуске открывается **менеджер проектов** (Project Manager) — окно со списком
проектов на компьютере. Каждый проект Godot — это папка с файлом ``project.godot`` и
всеми ресурсами игры. Номер установленной версии указан в правом нижнем углу
менеджера проектов.

Язык интерфейса Godot выбирается по языку операционной системы. В этой документации
названия элементов интерфейса приводятся на английском языке. Язык меняется кнопкой
**Settings** в правом верхнем углу менеджера проектов.


Создание проекта
----------------

1. Нажмите кнопку **Create** в левом верхнем углу менеджера проектов.
2. В поле **Project Name** введите название проекта.
3. В поле **Project Path** укажите расположение проекта. Если переключатель
   **Create Folder** включён, Godot создаст папку с названием проекта
   автоматически.
4. В группе **Renderer** оставьте вариант **Forward+**.
5. Убедитесь, что флажок **Edit Now** установлен, и нажмите **Create**.

.. screenshot:: 1

   Окно **Create New Project** с заполненными полями.

Параметр **Version Control Metadata** со значением **Git** добавляет в проект
служебные файлы для системы контроля версий Git. Если Вы не используете Git,
параметр можно оставить без изменений: на работу проекта он не влияет.


Рендерер
--------

Рендерер — подсистема, которая выводит изображение на экран. Его можно изменить
после создания проекта.

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Рендерер
     - Назначение
   * - Forward+
     - Настольные компьютеры. Полный набор возможностей.
   * - Mobile
     - Мобильные устройства.
   * - Compatibility
     - Слабые и старые устройства, а также публикация игры в веб-браузере.


Окно редактора
--------------

После создания проекта открывается редактор.

.. screenshot:: 2

   Редактор с пустым проектом.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Область
     - Назначение
   * - **Scene** (слева вверху)
     - Дерево узлов открытой сцены. Пока сцена пуста, здесь находятся кнопки
       создания корневого узла.
   * - **FileSystem** (слева внизу)
     - Файлы проекта. Путь ``res://`` обозначает папку проекта.
   * - Рабочая область (в центре)
     - Редактирование сцены или кода. Режим переключается вкладками **2D**,
       **3D**, **Script**, **Game** в верхней части окна.
   * - **Inspector** (справа)
     - Свойства выбранного узла или ресурса.
   * - Нижняя панель
     - Вкладки **Output** (вывод), **Debugger** (отладчик) и другие.
   * - Кнопки запуска (справа вверху)
     - Запуск, пауза и остановка игры.
