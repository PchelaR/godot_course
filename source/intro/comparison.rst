0.2. Godot, Unity и Unreal Engine
=================================

Сильные стороны Godot
---------------------

Лицензия
~~~~~~~~

Godot бесплатен без условий: отчисления с продаж отсутствуют при любом доходе игры.
Unreal Engine бесплатен, пока выручка игры не превышает 1 млн долларов США; сверх этой
суммы взимается 5% с продаж. Unity бесплатен, пока доход и привлечённые инвестиции
разработчика за последние 12 месяцев не превышают 200 тыс. долларов США; сверх этой
суммы требуется платная подписка Unity Pro, которая оплачивается за каждое рабочее
место.

Размер и установка
~~~~~~~~~~~~~~~~~~

Редактор Godot распаковывается из архива и запускается без установки и без учётной
записи; размер архива не превышает нескольких сотен мегабайт. Редактор Unity
устанавливается через Unity Hub, Unreal Engine — через Epic Games Launcher; оба
требуют учётной записи и занимают на диске несколько гигабайт.

Отсутствие устаревших подсистем
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Актуальная ветка Godot 4 выпущена в 2023 году и создавалась без сохранения обратной
совместимости. Для каждой задачи в движке существует одно актуальное решение. В Unity,
к примеру, существуют три конвейера рендеринга (Built-in, URP, HDRP) и две системы
ввода (Input Manager и Input System), и часть ассетов совместима только с одним из
вариантов.

Отдельный 2D-движок
~~~~~~~~~~~~~~~~~~~

2D в Godot реализовано отдельно от 3D, а координаты задаются в пикселях. В Unity
2D-объекты размещаются в трёхмерной сцене и отображаются ортографической камерой.
В Unreal Engine 2D поддерживается отдельным плагином Paper2D, а основное развитие
движка сосредоточено на 3D.

Простая модель
~~~~~~~~~~~~~~

Вся игра строится из узлов и сцен. В Unity объект и его поведение разделены на
``GameObject`` и компоненты, в Unreal Engine — на ``Actor`` и компоненты; в Godot
узел сам является и объектом, и единицей функциональности.

Открытый исходный код
~~~~~~~~~~~~~~~~~~~~~

Код Godot открыт полностью и распространяется по свободной лицензии. Исходный код
Unreal Engine доступен зарегистрированным пользователям, но не является открытым;
исходный код Unity закрыт.


В чём Godot уступает Unity
--------------------------

Готовые ресурсы
~~~~~~~~~~~~~~~

Магазин Unity Asset Store содержит значительно больше готовых моделей, анимаций,
звуков и плагинов, чем каталоги Godot (Asset Library и открытый в версии 4.7 Asset
Store). Для части задач, которые в Unity решаются покупкой готового пакета, в Godot
приходится писать собственное решение.

Встроенные сервисы
~~~~~~~~~~~~~~~~~~

Unity предоставляет собственные сервисы, интегрированные в редактор: рекламу,
внутриигровые покупки, аналитику, серверы для сетевой игры. В Godot собственных
сервисов нет: аналогичные возможности подключаются через плагины сторонних
поставщиков.

Большое количество объектов
~~~~~~~~~~~~~~~~~~~~~~~~~~~

В Unity есть набор технологий DOTS (Data-Oriented Technology Stack) с архитектурой
Entity Component System, рассчитанный на обработку десятков тысяч одновременно
действующих объектов. Встроенного аналога в Godot нет; при таких объёмах обработку
приходится оптимизировать вручную.

В чём Godot уступает Unreal Engine
----------------------------------

Фотореалистичная графика
~~~~~~~~~~~~~~~~~~~~~~~~

В Unreal Engine есть технологии Nanite (автоматический выбор детализации моделей
без ручного создания их упрощённых версий) и Lumen (динамическое глобальное
освещение), а также MetaHuman для создания реалистичных персонажей. Аналогов этих
технологий в Godot нет.

Nanite и Lumen рассчитаны на современные видеокарты и повышают системные требования
игры. Godot ориентирован на стилизованную графику и работает на более широком
диапазоне устройств, включая слабые компьютеры и веб-браузеры.

Большие миры
~~~~~~~~~~~~

В Unreal Engine есть встроенные средства для открытых миров большого размера:
система World Partition подгружает части мира по мере перемещения игрока, а
координаты хранятся с двойной точностью. В Godot автоматической подгрузки частей
мира нет, а двойная точность координат требует самостоятельной сборки движка из
исходного кода.

Визуальное программирование
~~~~~~~~~~~~~~~~~~~~~~~~~~~

В Unreal Engine игровую логику можно создавать без кода, в визуальном редакторе
Blueprints. В Godot визуальный редактор есть только для шейдеров, игровая логика
пишется кодом.

Инструменты для кино и анимации
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Unreal Engine используется в кино и на телевидении и содержит соответствующие
инструменты: редактор кат-сцен Sequencer, систему риггинга Control Rig. В Godot
анимация создаётся универсальными средствами — узлами AnimationPlayer и
AnimationTree; специализированных инструментов для кинопроизводства в нём нет.


Игровые консоли
---------------

Unity и Unreal Engine официально поддерживают экспорт на PlayStation, Xbox и Nintendo
Switch для разработчиков, зарегистрированных у производителей консолей; в Unity для
этого требуется подписка Unity Pro. Godot такой поддержки не имеет:
инструменты разработки для консолей распространяются по закрытым соглашениям с
производителями, что несовместимо с открытым исходным кодом. Экспорт на консоли
выполняют сторонние компании на коммерческой основе, например W4 Games.
