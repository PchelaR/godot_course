0.3. Язык GDScript
==================

**GDScript** — язык программирования, созданный разработчиками Godot специально для
движка. Это основной язык Godot, и на нём написаны все примеры этой документации.


Преимущества
------------

Простой синтаксис
~~~~~~~~~~~~~~~~~

Блоки кода выделяются отступами, как в Python. Синтаксис лаконичный, и файлы со
скриптами получаются короткими.

Встроенная интеграция с движком
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

В языке есть отдельный синтаксис для частых в Godot действий: обращения к узлам,
работы с сигналами, вывода переменных в редактор. Векторы, повороты и другие
математические типы, необходимые в играх, встроены в язык.

Ничего не нужно устанавливать
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Редактор кода, отладчик и справочная система встроены в Godot. Код запускается
сразу, без отдельной компиляции.

Основной язык документации
~~~~~~~~~~~~~~~~~~~~~~~~~~

Официальная документация Godot приводит примеры прежде всего на GDScript и
рекомендует его начинающим.


Ограничения
-----------

Похож на Python, но не Python
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Сходство ограничивается синтаксисом. Библиотеки Python в GDScript недоступны, а
поведение многих конструкций отличается. Опыт Python помогает читать код на
GDScript, но не заменяет изучения языка.

Используется только в Godot
~~~~~~~~~~~~~~~~~~~~~~~~~~~

GDScript не применяется за пределами движка. Общие навыки программирования
переносятся в другие языки, но сам язык — нет.

Производительность
~~~~~~~~~~~~~~~~~~

Код на GDScript исполняется виртуальной машиной движка и работает медленнее, чем код
на C# или C++. Для игровой логики разница обычно незаметна: основные затраты
приходятся на физику, графику и другие подсистемы, написанные на C++. Ресурсоёмкие
алгоритмы, например обработку больших массивов данных, при необходимости переносят на
C++.

Необязательная типизация
~~~~~~~~~~~~~~~~~~~~~~~~

Указывать типы переменных в GDScript не обязательно. Код без типов короче, но часть
ошибок в нём обнаруживается только во время работы игры, а не при написании кода.
Поэтому в этой документации типы указываются всегда.

Меньше готовых библиотек
~~~~~~~~~~~~~~~~~~~~~~~~

У GDScript нет менеджера пакетов и большой экосистемы библиотек, как у C# или
Python. Готовые решения распространяются в виде плагинов Godot.


Другие языки
------------

Godot также поддерживает:

- **C#** — для разработчиков, уже знакомых с языком. Требует отдельной версии
  редактора (Godot .NET) и внешнего редактора кода. Позволяет использовать
  библиотеки .NET.
- **C++** через систему GDExtension — для участков кода, требующих максимальной
  производительности.

В одном проекте можно использовать несколько языков.
