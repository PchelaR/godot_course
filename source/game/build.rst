3.23. Сборка игры
=================

Игра готова, но запускается только из редактора Godot. Чтобы в неё сыграл
кто-то ещё, её нужно собрать: превратить проект в файлы, которые запускаются
сами — программу для компьютера или страницу для браузера. В Godot это называется
:term:`экспортом проекта <Экспорт проекта>`. Он не имеет ничего общего с
``@export`` из главы 2.7, кроме слова.

Чего мы хотим: версии игры для Windows, macOS, Linux и браузера, которые можно
отдать другу или выложить в интернет. Чего не хотим: тащить в сборку то, что
игроку не нужно, — например, проверочные сцены.


Шаблоны экспорта
----------------

Редактор Godot умеет запускать игру, но не содержит готовых программ под каждую
систему. Эти программы — :term:`шаблоны экспорта <Шаблон экспорта>` — скачиваются
отдельно, один раз для каждой версии Godot: **Editor → Manage Export Templates →
Download and Install**. Версия шаблонов должна совпадать с версией редактора —
окно скачает нужные само.


Название и иконка
-----------------

Игрок увидит название игры в заголовке окна, а иконку — на панели задач. Задайте
их в **Project → Project Settings**, раздел **Application → Config**:
**Name** — название игры, **Icon** — картинка иконки. По умолчанию иконка —
логотип Godot.


Настройки сборки
----------------

Откройте **Project → Export**. Слева — список **предустановок**: для каждой
системы своя. Нажмите **Add...** и добавьте **Windows Desktop**, **macOS**,
**Linux** и **Web**. Настройки сохранятся в файл ``export_presets.cfg`` в корне
проекта.

На вкладке **Resources** каждой предустановки есть поле **Filters to exclude
files/folders from project** — какие файлы не включать в сборку. Впишите
``tests/*``: проверочные сцены нужны нам, а не игроку. Здесь и пригодилось, что
они лежат в отдельной папке (глава 3.3): одно правило — и всех их нет в сборке.

Для каждой системы:

1. Выберите предустановку и нажмите **Export Project...**.
2. Выберите папку и имя файла. Флажок **Export With Debug** снимите: отладочная
   сборка нужна разработчику, а не игроку.

**Windows.** Получится файл ``.exe`` и рядом файл ``.pck`` — упакованные ресурсы
игры. В разделе **Binary Format** включите **Embed PCK**: тогда всё окажется
внутри одного ``.exe``, и потерять половину игры при пересылке не получится.

**Linux.** То же самое, только программа без расширения ``.exe``. **Embed PCK**
работает и здесь.

**macOS.** Получится приложение ``.app``, упакованное в ``.zip``. Приложение не
подписано сертификатом разработчика Apple, поэтому при первом запуске macOS его
не откроет. Игрок разрешает запуск сам: **System Settings → Privacy & Security
→ Open Anyway**.

Windows тоже предупреждает о неподписанных программах: в окне «Windows protected
your PC» нужно нажать **More info → Run anyway**. Подпись приложений — платная
услуга, и для игры, которую отдают друзьям, без неё обходятся.


Игра в браузере
---------------

Сборка **Web** — это страница ``index.html`` и несколько файлов рядом с ней:
движок (``.wasm`` и ``.js``) и ресурсы игры (``.pck``). Имя ``index.html``
оставьте как есть: по нему сайты находят, что запускать.

Открыть ``index.html`` двойным щелчком не получится: браузер не даст странице,
открытой с диска, загрузить остальные файлы. Её нужно открывать с веб-сервера.
Проверить сборку проще всего прямо из редактора. Когда добавлена предустановка
Web, в правом верхнем углу редактора появляется кнопка с иконкой браузера: она
собирает игру, запускает маленький сервер на Вашем компьютере и открывает игру в
браузере.

Чтобы выложить игру для всех, подойдёт itch.io — бесплатная площадка для
небольших игр:

1. Запакуйте все файлы сборки Web в один ``.zip`` — так, чтобы ``index.html``
   лежал в корне архива, а не во вложенной папке.
2. На itch.io создайте проект, в **Kind of project** выберите **HTML** и
   загрузите архив. Отметьте **This file will be played in the browser**.
3. В **Embed options** задайте размер окна ``1200`` × ``768`` — наш экран,
   увеличенный в 3 раза, — и включите кнопку полноэкранного режима.

Рекорд из главы 3.20 в браузере тоже сохраняется: ``user://`` там — хранилище
браузера, и рекорд переживёт закрытие вкладки.

Готовый проект игры — из прошлой главы: :project:`maze/22_sound`.
